# ATRAVOZ 0.2.0-test

No Android, transfira o APK para o aparelho e abra o arquivo para iniciar a instalação. A compilação usa assinatura de desenvolvimento. [Baixar APK](ATRAVOZ-Cidadao-0.2.0-test.apk)

No Windows, extraia o ZIP completo e abra `ATRAVOZ-Central.exe` com a pasta `_internal` ao lado. O iniciador atende em loopback por padrão. O acesso pelo celular exige uma origem HTTPS confiável para a mesma API. [Baixar pacote Windows](ATRAVOZ-Central-Windows-0.2.0-test.zip)

Os pacotes foram compilados a partir de `5d7e07abac5fcb25fe44dc1eada4276ec1fa4d58`. A entrega foi validada no computador. Instalação e Bluetooth entre celulares ainda precisam de teste físico. [Relatório de validação](../../docs/INSTALLERS_FINAL_REPORT.md) · [Roteiro de teste](../../docs/NATIVE_TRANSPORT.md)

Confira a integridade com `Get-FileHash -Algorithm SHA256` no PowerShell e compare os valores. [SHA256SUMS.txt](SHA256SUMS.txt)
