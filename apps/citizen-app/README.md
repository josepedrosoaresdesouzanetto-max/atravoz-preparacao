# Aplicativo do cidadão

Objetivo: registro persistente antes de qualquer envio. Responsabilidade sugerida: desenvolvedor 1. Dependências: React, contratos compartilhados e API. Entrada: relato opcional. Saída prevista: ocorrência UUID e recibo persistido. Execute `npm run dev` na raiz e abra `/`. Testes: `npm test`. Marco inicial contém interface executável; armazenamento e mídia ainda pendentes. Risco: navegador pode suspender execução ou remover dados sob pressão de armazenamento.
