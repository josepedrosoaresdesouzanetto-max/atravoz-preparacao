# Dados, IA e Qualidade

Responsabilidade proposta: idealizador. Objetivo: preservar original e organizar uma cópia, sem decidir resgate. Dependências: Python, Pydantic; adaptadores substituíveis. Testes: `.venv/Scripts/python -m pytest -q`. Entrada inicial: texto Unicode; saída: cópia normalizada. Marco inicial: normalização funcional. Próxima fase prioritária: contratos, extração com evidências, fallback, provedor de modelo, avaliação sintética e relatório de limitações. Risco: extrações podem estar erradas mesmo quando válidas no formato; revisão humana obrigatória.
