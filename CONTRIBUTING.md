# Contribuir

Leia README e os contratos antes de modificar um módulo. Papéis são provisórios. Use dados sintéticos, execute testes, preserve IDs e o relato original. Documente contribuições humanas e assistidas por IA separadamente. Não atribua revisões não realizadas. Não publique, faça push, PR ou deploy após o único envio inicial sem nova autorização do proprietário.
