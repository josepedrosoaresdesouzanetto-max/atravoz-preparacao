# Central demonstrativa

Responsabilidade sugerida: desenvolvedor 3. Objetivo: mostrar somente registros recebidos pela API. Entrada: respostas autenticadas da API; saída prevista: revisões humanas auditadas. Execute `npm run dev` e abra `/central.html`. Testes: `npm test`. Marco inicial contém interface executável; consultas autenticadas e detalhes serão integrados localmente. Nunca representa central oficial.
