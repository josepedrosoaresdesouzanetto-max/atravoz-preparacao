# Contratos compartilhados

Versão inicial: 1. UUID estável; registro `help` ou `witness`; descrição opcional até 4000 caracteres; apenas dados sintéticos. Contrato TypeScript validado por Zod. Testes na raiz com `npm test`. O esquema JSON será exportado do modelo canônico Python após consolidar o protocolo e verificado nos clientes. Versões incompatíveis devem falhar sem excluir registros locais.
