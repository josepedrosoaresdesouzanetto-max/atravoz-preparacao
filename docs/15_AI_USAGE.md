# Uso de IA

Ferramenta: Codex, agente baseado em GPT-6 conforme identificação desta sessão. O nome Astra é usado pelo pedido; não é uma validação independente do modelo. Objetivo: transformar requisitos humanos em software, testes e documentação.

Marco inicial gerado: interfaces React, contrato Zod, API de saúde FastAPI, normalização Python, testes e CI. Não houve revisão humana registrada. Instalação e testes têm evidências no diário; não confundir código gerado com executado.

Pendente: revisão da equipe, validação do público, análise jurídica de retenção e segurança de produção. O fallback determinístico previsto não será apresentado como modelo generativo.
