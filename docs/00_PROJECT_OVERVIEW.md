# Visão do projeto

ATRAVOZ (atravessar + voz) é nome provisório. Missão: preservar e transportar informação essencial sob conexão instável. Contexto inicial: chuvas extremas na Região Metropolitana do Recife; adaptação mundial é visão futura, não escala demonstrada.

Cenário B: o mesmo aparelho recupera conexão e envia sua fila persistente. Implementado e testado no navegador desktop com viewport móvel. Cenário A: outro celular transporta o registro. Não implementado em rádio; apenas protocolo de laboratório testado.

O produto separa três responsabilidades: cidadão registra; API confirma armazenamento técnico; operador revisa. Nenhum componente aciona atendimento real. A análise auxilia a organização e pode falhar sem impedir o recebimento.

Preparação privada anterior ao evento. O valor a validar é se pessoas compreendem o estado da informação e conseguem registrar com pouca fricção. Não há pesquisa de campo, impacto comprovado ou vidas salvas atribuídos ao protótipo.
