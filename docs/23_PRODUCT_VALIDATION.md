# Protocolo de validação humana — ainda não executado

Usar dados fictícios, explicar que não é serviço de emergência e obter concordância do participante. A pessoa deve poder parar sem justificativa. Não recolher nome completo, relato traumático real ou localização pessoal. O validador Pró-Criança ainda não foi designado nesta preparação.

Tarefas: abrir app; interpretar os dois botões; salvar mínimo sem digitar; identificar onde os dados estão; reabrir sem rede; acrescentar voz quando desejado; recusar câmera/GPS e continuar; restaurar rede; interpretar recibo e anexo pendente; localizar orientação dos canais oficiais; explicar diferença entre envio e atendimento.
